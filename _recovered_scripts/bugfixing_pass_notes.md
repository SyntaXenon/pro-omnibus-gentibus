## RESOLVED: Año A/B/C cycle-variant text had no selection logic anywhere (code fix)
breviarium-core stores some Sunday-cycle-dependent text (Advent 1 Sunday's Benedictus antiphon, several Easter Sunday Vespers gospel-canticle antiphons in the Latin overlay, ~30 Ordinary Time Sunday commons entries) as a single string shaped `"$ Año A: $<text A>\n$Año B: $<text B>\n$Año C: $<text C>"`. The client-side `mdLite()` renderer has zero awareness of this format and was concatenating all three years into one bolded blob. Fixed in `app/renderer/render_day.py`: added `year_letter_for_date(d)`, `_select_year_variant(text, year_letter)`, `_apply_year_variant_selection(extras, year_letter)`, applied inside `breviarium_primary_hour_units` (both the Spanish `extras` side and the separate Latin `latin_ants` side, which is a distinct dict not covered by the `extras` transform) whenever a real date `d` is passed. Threaded `d` through all 17 call sites of `breviarium_primary_hour_units` plus `memorial_proper_hour_units`'s own signature/callers. One subtlety: the Saturday-before-Advent-1 First Vespers call site needed `d + timedelta(days=1)` (tomorrow's date), not `d`, since the lectionary cycle year for that Vespers belongs to the Sunday being anticipated, not the Saturday itself.

Separately verified this does NOT affect Ordinary Time Sundays' own antiphons in practice: `build_sunday_units` (the code path actually used for regular OT Sundays) sources its gospel-canticle antiphon from `content/proper_texts/{lang}.json` (a clean, psalter-week-keyed static file matching the real physical breviary's fixed 4-week antiphon structure), never from `extras.get("cantico_evangelico_antifona")` - so the ~30 Año-variant commons entries linked from `ordinary_time_N_sunday` ids are inert/unused data, not a live rendering bug. Verified via `content/proper_texts/` grep (no "Año" text present there) and via code trace (breviarium_primary_hour_units is never called with an `ordinary_time_N_sunday`-pattern id).

Verified working: 4-year stress test clean (0 errors, 2026-2029); Advent 1 Sunday's Benedictus antiphon confirmed rendering as a single clean per-year text (not the "Año" blob) for 2026(B)/2027(C)/2028(A).
